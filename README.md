# ITIScloud

Un **cloud personale** in PHP e MySQL per archiviare e consultare i propri file: documenti,
musica, foto e altri media. Progetto scolastico server-side con registrazione e login utenti.

## Funzionalità

- Registrazione e autenticazione degli utenti
- Upload e download di file
- Sezioni dedicate: musica, foto, film &amp; media
- Area personale per ogni utente

## Stack tecnologico

- **PHP** (server-side)
- **MySQL** (schema in `tabelle.sql`)
- HTML / CSS

## Avvio

1. Importa `tabelle.sql` nel tuo server MySQL.
2. Configura i parametri di connessione al database.
3. Servi la cartella con un server PHP (es. Apache/XAMPP o `php -S localhost:8000`).
